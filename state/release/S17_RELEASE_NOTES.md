# NeuroCVguard 0.1.0 — release notes draft

UNRELEASED. No release date, public installation, citation identifier or human
review is claimed. Confirm metadata and replace this status only after the actual
approved release. This draft is prepared locally for the owner to review.

NeuroCVguard checks whether supplied local cohort identities, split plans and
controlled evaluation procedures match a stated generalization objective. It
supports explicit observation-key joins, participant and transitive dependency
protection, objective-dependent domain checks, descriptive acquisition/target
association, declared preprocessing audits and checked grouped split generation.
Its participant-level logistic classification baseline includes optional nested
C selection. Offline HTML/JSON reports distinguish detected findings, incomplete
coverage, undefined metrics and privacy suppression. Five fully synthetic examples
are included. No GPU, account or runtime internet connection is required.

Scientific limits: repeated observations alone are not leakage; shared sites
matter according to the chosen objective. Unknown upstream preprocessing stays
unassessable. Association and score differences do not establish causality.
Evaluation requires constant participant targets and the supported complete-CV
classification design. Regression, changing longitudinal targets and temporal
evaluation are unsupported. Undefined metrics retain null values and reasons;
failed folds remain visible. No clinical certificate, global leakage-free verdict
or anonymity guarantee is provided.

Private evaluation records can carry paired plan_digest/actual_plan fields;
comparison records can carry optional typed design context. Updated readers accept
legacy records without inventing missing context. Older closed-schema readers need
updating for these extensions. Operational split plans/evaluations remain sensitive
and are separate from privacy-projected public reports.
