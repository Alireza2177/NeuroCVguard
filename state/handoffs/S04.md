## Scientific and privacy review

[review.md](../../qa/evidence/S04/review.md) records implementation-AI review,
not independent or human acceptance. Repeated training membership across folds
is allowed; actual within-split person/component overlap is checked. Shared
sites are objective-dependent. Participant-local sessions never define separate
people. Nested assignments cannot see outer test; inner domains are not silently
held out. Missing training classes block the fold; missing test classes warn
without scores. Unknown IDs block dependent checks without discarding the fold.

The existing strict AuditReport contract is retained. Its scoped NCG-SPLIT-011
summary separates valid_for_objective, complete_cv and ordinary split-level
evaluation_permitted. This last field does not claim features are available or
an evaluator exists. Unknown upstream preprocessing remains NCG-PROV-001
not_assessable, so technical execution status is partial even for valid splits.
No global leakage-free verdict, causality claim, fit or score was added.

Public projection omits membership IDs, raw labels, component hashes and open
evidence; fold/repeat labels are aliased. Only typed summary flags/counts remain.
Detailed memberships stay in explicit sensitive exports. No application output
writer, telemetry, dataset download or external publication was introduced.
