## Scientific and privacy review

The implementing Codex agent reviewed the scientific and privacy boundaries;
see qa/evidence/S06/review.md and instruction_loading.md for actual sources and
scope. No independent AI reviewer or human review is claimed.

Each pair requires stable target and field within every participant. Missing
values can exclude participants only from complete-pair diagnostic counts;
the original cohort remains intact. Instability blocks the whole pair. Evidence
distinguishes n_complete from n_in_table when an otherwise complete subset
cannot be used. Family members are counted without asserting independence.

V uses uncorrected Pearson chi-square via SciPy, not a bias correction or
inferential test. No p-value, permutation, category merging or causal verdict
is produced. The default 0.3 is an operational review threshold; warnings are
conditional on the declared generalization objective. The guide acknowledges
mlconfound through the foundation's R09 source without claiming equivalent tests.

Default public projection omits all linked association numbers, labels, raw
columns and tables, including values from non-sparse tables. This conservative
existing serializer extension avoids reconstruction from denominators or V.
Explicit sensitive serialization retains local evidence. Rich table display and
aliasing remain later-stage work. Undefined-statistic reasons are whitelisted
for public output. No HTML/report renderer was added.
