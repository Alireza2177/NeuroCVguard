## Scope delivered

Implemented REQ-S12, covering AT-S12-01 through AT-S12-09. The user explicitly
requested S12 after completed S11 and its recorded checks, and separately approved
the optional comparison context extension. This authorizes continuation without
claiming predecessor acceptance or human scientific review. S13 and later stages
remain NOT_STARTED. No commit, push, publication or patient-data access occurred.

`comparison.py` adds strict bounded private evaluation loading and
`compare_designs`, exported from the package root. At least two named operational
records are required. Comparisons revalidate inputs and preserve signed A-minus-B
participant metric differences, null/mismatch reasons and incomplete designs.
They never fit, hunt seeds, rank scientific designs or infer a causal leakage amount.

`_diagnostics.py`, `_evaluation_inputs.py` and `evaluation.py` implement only the
explicit outer participant-overlap exception for unseen_participant, without
extra independence columns. All other structural/class guards remain. Split
audit judgments are unchanged. Diagnostic pooling checks observation OOF coverage
and averages all raw held-out rows once per participant, including unequal visit
counts across folds. Failed folds prevent pooled complete-CV scores. Nested
selection keeps participant-disjoint inner folds on outer training only.

`models.py`, `rules.py`, `_projection.py`, `cli.py` and `templates/report.html`
add typed comparison context, the diagnostic warning rule, public projection,
the `compare --result NAME=PATH` command and readable context/metric/difference
tables. CLI/HTML warnings state invalidity for unseen-participant evidence.
Public reports use design/digest aliases; metrics and dependent differences are
suppressed together for small cells and remain suppressed on rerendering.
HTML escapes supplied text, and existing output files require explicit overwrite.

The approved optional context extension updates both normative comparison/audit
schemas and their packaged copies, spec §20.9 and the generated reading editions.
It adds recorded counts, objectives' supporting context, metric units, classes,
local identity-equivalence aliases and prescribed model/recorded C details.
Unrecorded model settings require the original configuration. Legacy records
remain readable without invented context; older closed-schema readers must update.

Added `tests/test_comparison.py`, `tests/test_diagnostic_evaluation.py` and
`tests/test_comparison_cli.py`. Adjusted the prior CLI capability test, the now
implemented diagnostic-option guard and explicit UTF-8 report decoding. Added
