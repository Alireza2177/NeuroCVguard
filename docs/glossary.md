# Glossary

| Term | Meaning |
|---|---|
| Observation | One explicit keyed row, such as a scan or visit |
| Participant | A physical person represented by a stable global ID |
| Session | A participant-local visit label, never a global person ID |
| Protected component | Transitive closure across declared dependence fields |
| Domain | Site or phase selected for the generalization objective |
| Observed evidence | A directly computed property of supplied data or controlled runtime |
| Declared evidence | An unauthenticated assertion supplied by a user |
| Heuristic evidence | A review signal, such as identical feature vectors |
| Unassessable | Required information is unavailable; not a passing check |
| Operational artifact | Identity-bearing plan, ledger or private evaluation |
| Projection | Explicit removal/suppression for reports; not anonymization |
| OOF | Out-of-fold predictions from rows withheld from that fit |
| Undefined metric | JSON null with a mathematical reason and denominator |
| Incomplete evaluation | At least one failed fold; no complete pooled score |
| Diagnostic-only | Explicitly invalid overlap experiment, not evidence of generalization |
